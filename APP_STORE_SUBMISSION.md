## App Privacy proposée

- Suivi : non
- Publicité tierce : non
- Analytics : non
- Identifiants / ID utilisateur : utilisés pour la fonctionnalité de l’app via Game Center
- Contenu de jeu / historique : utilisé pour la fonctionnalité de l’app, stocké dans la base CloudKit privée de l’utilisateur

À confirmer dans App Store Connect selon les pratiques réelles et la définition Apple de « collecte » pour les données traitées uniquement par les services Apple.
